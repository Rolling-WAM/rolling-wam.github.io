LOCAL FONT GLYPH EXPORTS — PROVENANCE AND LICENSES

These SVGs contain the exact arXiv and GitHub outlines extracted from the local
font files listed below. No external assets were downloaded. Font outlines were
not redrawn or reshaped; SVG coordinate transforms convert font y-up coordinates
to SVG y-down coordinates. The standard font viewBoxes preserve icon proportions.

Source: Academicons font (academicons.ttf), https://jpswalsh.github.io/academicons/

SVG viewBox: 0 0 448 512
