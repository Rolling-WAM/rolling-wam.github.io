# rolling-wam.github.io

Project website for **Rolling-WAM: World Action Models with Rolling Imagination**.

**Website:** https://rolling-wam.github.io/

This is a static website. GitHub Pages publishes the root of the `main` branch; no build step is required.

## Files

- `index.html`: page content, authors, figures, experiments, and citation.
- `styles.css`: layout and visual styling.
- `rolling-cycle.js` and `script.js`: method animation and page interactions.
- `site-config.js`: paper and code links. Add the arXiv URL here when available.
- `assets/`: figures, videos, icons, and icon license notices.

Open `index.html` for a local preview. Push changes to `main` to update the live site.
